# Analytics Dashboard

A front-end analytics dashboard where users can view business metrics, filter data, review charts, and scan summary cards in a responsive layout.

## Live Demo

https://jfoster294.github.io/analytics-dashboard/

## Features

- Revenue summary card
- User summary card
- Orders summary card
- Conversion rate summary card
- Filter by time period
- Filter by category
- Revenue line chart
- Orders by category bar chart
- Sales activity table
- Saved filter preferences with local storage
- Responsive dashboard layout

## Built With

- HTML
- CSS
- JavaScript
- SVG
- Local Storage

## Project Goal

This project was built as part of my front-end developer portfolio to practice dashboard layouts, data filtering, chart rendering, table rendering, local storage, and responsive design.
